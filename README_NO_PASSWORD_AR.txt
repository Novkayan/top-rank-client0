توب رانك للخدمات المنزلية — واجهة العميل بدون كلمة مرور

تم تعديل واجهة العميل فقط. لوحة الأدمن تظل محمية بالبريد وكلمة المرور.

خطوة ضرورية داخل Supabase:
Authentication → Providers → Anonymous Sign-ins → Enable
(قد يختلف اسم القائمة حسب واجهة Supabase).

العميل يفتح الموقع ويحجز مباشرة. ينشئ Supabase جلسة مجهولة آمنة مرتبطة بهذا المتصفح، وRLS يحصر عرض حجوزاته في معرفه فقط.
إذا حذف العميل بيانات المتصفح أو غيّر الجهاز، قد لا يتمكن من الوصول إلى حجوزاته السابقة؛ لا توجد آلية استرجاع برقم الجوال في هذه النسخة.

ارفع الملفات كلها إلى مستودع العميل فقط واستبدل الملفات القديمة. لا ترفع هذه الملفات لمستودع الأدمن.

ملاحظة: لم يتم اختبار الحجز الحي على قاعدة Supabase. يجب اختبار Anonymous Sign-ins والحجز والقراءة قبل التسليم.
